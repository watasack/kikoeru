# 聞こえる街

防災無線のスピーカーの音が、建物に遮られて届かない家を、3D都市モデル（PLATEAU・金沢市）から見つけ、スピーカーや戸別受信機の配置を予算ごとに比べるビューアです。PLATEAU AWARD 2026 応募作品。

数値はモデルの計算値で、実測との比較はありません（反射は2次まで、吸音率0.1、1 kHz 単一帯域などは仮定）。

## 開き方
公開ページの `web2/index.html`（ルートの index.html から自動で移動します）。ローカルでは、このフォルダーで `python -m http.server 8718` を実行し、`http://127.0.0.1:8718/` を開きます（`file://` では動きません）。
